# "Afasta o celular" (thread 109, 21/11/2026)
Imagem híbrida (Oliva, Torralba e Schyns, MIT/Glasgow): baixa frequência de uma imagem + alta frequência de outra.
De perto o olho pega os traços finos; de longe (ou apertando os olhos) só as manchas -> a imagem troca.
Nível 1 gato -> cachorro, nível 2 carinha feliz -> chorando, nível 3 "TE AMO" -> "ME PAGA" (pra mandar pra quem te deve).
Pagamento garantido: depois de cada tentativa o quadro ENCOLHE na tela (pequeno = longe de verdade), então 100% vê a troca.
Por que pode viralizar: acontece com a própria pessoa (como "no teu olho"/bandeira), pedido na tela no quadro 0,
3 viradas em 48 s, final engraçado feito pra compartilhar ("manda pra quem te deve").
Imagens: hibrida.py + gerar_imgs.py (Twemoji CC-BY via npm @twemoji/svg, Inter Display) -> hibridas.js (24 tamanhos já reduzidos).
As imagens ficam fora da camada de tinta (sem o filtro "marker", que borraria os traços finos).
Voz Algieba (gemini-3.1-flash-tts-preview, take único), audio.py (tiques nas tentativas, ding nas revelações).
